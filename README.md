# SC 转发扩展 for LAPLACE Chat

适用于 LAPLACE Chat 的独立第三方 Chrome 和 Edge 扩展。在 `chat.laplace.live` 或 `laplace.chat` 的单房间控制台点击 SC 卡片右上角的纸飞机，即可用已验证的 B 站账号把正文发送成普通弹幕。

## 安装和绑定账号

1. 下载或克隆本仓库。若需要本机 Login Sync，在安装了 Node.js 和 npm 的 Windows x64 上运行 [Install-SC-Relay.cmd](Install-SC-Relay.cmd)。脚本会安装固定版本的依赖并启动服务。使用 Edge 时运行 `Install-SC-Relay.cmd -Browser Edge`。
2. 在 `chrome://extensions` 或 `edge://extensions` 加载 `laplace-sc-replay`。新安装时选择「加载已解压的扩展程序」。已有安装点击扩展卡片的重新加载图标。
3. 刷新 LAPLACE Chat，点击 SC 栏齿轮，展开「发送账号」。

### 本机 Login Sync

1. 在同一个浏览器窗口中登录想要保存的 B 站账号。在发送账号设置选择「本机 Login Sync」，点击「生成当前登录账号的密钥」。首次生成请按提示授权读取 B 站会话。
2. 密钥会自动填入「本机身份密钥」。点击「验证并记录」，核对显示的 B 站昵称和 UID。已有本机密钥也可以直接填入。
3. 登录另一个 B 站账号后重复上述步骤。用「已记录的账号」选择昵称，再点击「使用选中账号」。发送账号与网页当前登录分开，浏览器关闭后仍保留记录和选择。

服务只监听 `127.0.0.1:18188`，B 站会话以加密形式存于 `login-sync-local/data`。Windows 重启后重新运行 `Install-SC-Relay.cmd` 启动服务。点击「检查会话」可以验证选中账号的状态。B 站会话失效时，在当前窗口重新登录该账号，选中对应记录并点击「更新会话」，即可用原密钥继续使用。需要保留多个账号的有效登录时，可分别在普通窗口和无痕窗口登录，避免主动退出 B 站。无痕窗口需要在浏览器扩展详情中允许本扩展运行。

### 已登录的 B 站会话

在想用于发送的窗口登录 B 站，点击「读取浏览器会话」，授权后选择对应的窗口。扩展使用你手动绑定的账号，并显示昵称和 UID。若要在同一个 Chrome 用户资料里同时登录两个账号，可分别使用普通窗口和无痕窗口。选择无痕窗口时，请在扩展详情中启用「在无痕模式下允许」，并保持至少一个无痕窗口打开。不同 Chrome 用户资料中的账号可以在各自的资料内安装和使用本扩展。 [Chrome 会话隔离说明](https://developer.chrome.com/docs/extensions/reference/api/cookies)

### LAPLACE Login Sync 身份密钥

只有在已获同步服务读取授权的情况下使用此模式。在「账号来源」选择「LAPLACE Login Sync 身份密钥」，填写身份密钥和服务端要求的读取授权。LAPLACE Chat 已于 2026 年 5 月取消对第三方浏览器扩展同步的支持。个人用户可使用前两种账号来源。 [Login Sync 文档](https://laplace.live/login-sync) · [LAPLACE Chat 更新日志 #202](https://laplace.live/chat/changelog) · [上游 SDK 授权说明](third-party/login-sync/README.md)

## 使用

- 点击 SC 卡片上的纸飞机。齿轮可设置前缀、后缀、单条长度和自动分段间隔。前后缀默认分别为 `【` 和 `】`，可自行修改或清空。
- 长文优先按句末标点和逗号断开。每段计入前后缀，默认单条长度 20，间隔 2 秒。B 站拒绝某段或结果无法确认时，停止剩余分段，并提示已经收到成功回执的条数。
- 转发前比对左侧普通弹幕和本扩展在同一房间近期已成功转发的 SC。齿轮可调整查重时长（默认 60 秒）和相似度阈值（默认 100%）。相似度按增、删、改字符的次数计算，达到阈值即跳过。左侧弹幕的分段须由同一发言者按顺序发齐，没有时间戳的弹幕从扩展观察到实时新增时计时。成功转发记录在浏览器会话内保留，刷新控制台后仍可参与查重。
- 命中时提示会显示实际相似度并自动淡出。默认可在提示期间双击同一条 SC 的纸飞机继续转发，提示消失后自动标记已读。关闭设置中的「提示期间可双击强制发送」后，命中即标记已读。
- 全部分段发送成功后，扩展触发控制台原有的双击标已读操作。控制台接受时按现有已读设置变灰或隐藏，未接受时当前卡片由扩展显示为灰色。
- 使用「已登录的 B 站会话」时，如果该窗口切换了账号，扩展会暂停发送，直到重新绑定确认 UID。发送目标取自当前控制台房号，发送前由 B 站解析成实际房号。

## 发送链路

Chatterbox 5.0.0 在 B 站直播页读取 `bili_jct`，由网页会话携带登录 Cookie，并向 B 站直播的 `/msg/send` 发送表单。它的多账号功能让各个浏览器或用户资料分别登录，发言请求使用各自会话。本扩展使用相同的普通弹幕请求。后台从选中的浏览器会话取出该账号的 Cookie，或通过 Login Sync SDK 解密同步数据，随后核对 UID、解析房间号、提交表单并检查 B 站回执。 [Chatterbox 发布脚本](https://downloads.vrp.moe/chatterbox/laplace-chatterbox.user.js) · [多账号方式](https://laplace.live/chatterbox/copy-ninja)

## 数据与权限

账号区域通过扩展自身的页面隔离密钥输入。读取浏览器会话和生成或更新本机密钥时，扩展会请求 Cookie 权限，并从用户选定的窗口读取发送所需的 B 站 Cookie。浏览器会话模式保存窗口标识和 UID，本机模式将会话保存为本机密文，外部同步服务模式在浏览器会话中保存密钥和读取授权。账号校验和弹幕发送请求发往 B 站。查重使用当前房间的可见普通弹幕和浏览器会话内的短期转发记录。

本项目通过浏览器扩展读取 LAPLACE Chat 控制台中的可见事件，转发由用户点击触发。请按 LAPLACE 和 B 站的使用规则操作。 [LAPLACE 使用条款](https://laplace.live/tos)
